# 시립도서관 열람실 좌석 예약 — 화면 흐름

## 사이트

- 기관명: 시립도서관
- 메뉴: 좌석 예약(좌석 현황, 예약 신청) · 내 예약 · 이용 안내

## 화면

| ID | 화면 | 하는 일 |
|---|---|---|
| SCR-01 | 좌석 현황 조회 | 열람실·날짜로 검색, 열람실별 잔여 좌석 목록, 행마다 "예약" 버튼 |
| SCR-02 | 좌석 예약 신청 | 4단계 신청 — ① 좌석 선택 ② 이용 시간 ③ 이용자 정보 ④ 확인 |
| SCR-03 | 예약 완료 | 예약번호·좌석·시간 요약, "내 예약 보기" 링크 |

## 흐름

좌석 현황 조회 → (예약) → 좌석 선택 → 이용 시간 → 이용자 정보 → 확인 → 예약 완료

## 화면별 항목

### SCR-01 좌석 현황 조회
- 검색: 열람실(선택: 제1열람실, 제2열람실, 노트북열람실), 이용일(날짜)
- 목록 열: 열람실, 층, 전체 좌석, 잔여 좌석, 운영 시간, 상태(여유·혼잡·마감), 예약
- 마감인 행은 예약 버튼 비활성

### SCR-02 좌석 예약 신청
- 1단계 좌석 선택: 열람실(표시만), 좌석 번호(선택), 창가석 여부(체크)
- 2단계 이용 시간: 시작 시각, 이용 시간(2·3·4시간 중 라디오)
- 3단계 이용자 정보: 이름(필수), 도서관 회원번호(필수), 휴대전화(선택), 안내 문자 수신 동의(체크)
- 4단계 확인: 입력 내용 요약, 이용 수칙 동의(필수 체크), "예약하기"
- 필수 항목을 비우고 다음으로 가면 항목 아래 오류 문구를 보여 준다

### SCR-03 예약 완료
- 예약번호(예: LIB-2026-0412), 열람실·좌석·시간 요약
- 버튼: 내 예약 보기, 처음으로
